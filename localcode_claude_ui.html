Cómo conectar Ollama con esta app
  1. Instala el modelo si no lo tienes: ollama pull qwen2.5-coder:7b (o deepseek-coder-v2).
  2. Arranca Ollama permitiendo este origen: en la terminal, ejecuta OLLAMA_ORIGINS=* ollama serve (en Windows, define la variable de entorno OLLAMA_ORIGINS=* antes de iniciar el servicio).
  3. Verifica que responde visitando http://localhost:11434 en tu navegador — debe decir "Ollama is running".
  4. Escribe la URL y el nombre exacto del modelo arriba (debe coincidir con ollama list).
  5. Si el estado sigue en rojo: abre este archivo directamente en tu navegador como file://... o arráncalo con python -m http.server 8000.
