## Known Limitations Documented
1. **Pytest Exit Code 5**: When verification runs on a workspace without modified test files, `pytest` returns exit code 5 (`EXIT_NOTESTSCOLLECTED`). `_stage_verifier` intercepts this deterministically, reporting `tests_status = NOT_REQUIRED` and `tests_passed = True`.
2. **Abrupt Process Termination on Windows**: `TerminateProcess` on Windows terminates parent processes without executing `atexit` hooks. `_start_parent_monitor()` in `localcode_server.py` detects parent loss via Windows Native API in $< 4$ seconds, releasing TCP sockets.
