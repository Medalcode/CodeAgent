GRADE A (SAFE EXTRACT): 2 candidates
  - State Machine Interface: Extract state machine mechanics while keeping pipeline orchestration
  - Task Contract Bridge: Move canonical contract logic to sdd_contract (ALREADY DONE in C3.3)

GRADE B (CONTROLLED): 1 candidate

GRADE C (DEFER): 2 candidates
  - Checkpoint/Persistence: Critical C3.1 feature, dual ownership design
  - Task Classification: Core pipeline behavior

GRADE D (DO NOT EXTRACT): 1 candidate

OVERALL ASSESSMENT:

- 1 controlled extraction feasible with test adaptation
- 3 should be deferred or avoided

- Cross-cutting concerns (error handling, configuration, serialization) should remain as utilities
