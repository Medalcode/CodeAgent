**Key Rule**: Never start by the most complex extraction. Begin with Grade A safe extractions, progress to Grade B controlled extractions, and avoid Grades C/D entirely during D0.

### Test Strategy for Extractions

- **Grade A extractions**: Must have test coverage BEFORE extraction; migration tests verify behavior preservation
- **Grade B extractions**: Existing tests must pass; new tests in new module; migration tests
- **Grade C/D extractions**: Do not attempt during D0; document as technical debt for D1+

## Rollback Strategy

For each extraction:
1. **Version control**: git tag before extraction
2. **Behavior tests**: Run full pytest suite before and after
3. **Contract tests**: Verify sdd_contract authority preserved
4. **Rollback command**: `git reset --hard <tag>`
5. **Verification**: SDD check must still PASS

## Expected Architectural Improvements

- Grade A extractions: Cleaner separation of concerns; sdd_contract as sole canonical authority
- Grade B extractions: Modularize self-contained concerns; improve code organization
- Avoid Grades C/D: Preserve pipeline integrity; avoid fragmentation that would increase coupling
